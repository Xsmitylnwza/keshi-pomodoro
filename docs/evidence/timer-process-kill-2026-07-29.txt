Method
------
For each completion boundary, a real Pomodoro API child process:
1. started a focus timer against a unique temporary data directory;
2. durably wrote the selected completion projection;
3. emitted a test-only marker after the atomic write completed;
4. was terminated by its parent with SIGKILL;
5. was restarted against the exact same data directory;
6. received the exact same completion command again.

The pause hook is active only when NODE_ENV=test and accepts a marker path only
below POMODORO_DATA_DIR. Production environments cannot activate it.
